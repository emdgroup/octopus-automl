# Octopus documentation

The docs are built with [ProperDocs](https://pypi.org/project/properdocs/). The configuration is in `properdocs.yml` at the repository root.

## Preview locally

Run from the repository root:

```bash
uv sync --extra docs      # or: pip install -e ".[docs]"
uv run properdocs serve   # http://127.0.0.1:8000, reloads on changes
```

## Build

```bash
uv run properdocs build   # static site is written to site/
```

The `docs` extra also installs the `examples` and `test` extras, because the example pages are generated by running the examples.
